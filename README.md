# Hostel Booking Professional Project

A multi-admin hostel booking web application developed using **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript**. The platform allows a **Super Admin** to manage multiple hostel administrators, while each administrator independently manages their own hostels, rooms, bookings, and customers.

## 🚀 Features

### Super Admin

* Secure Login
* Dashboard
* Manage Admin Accounts (Create, Update, Delete)
* Approve or Disable Admin Accounts
* View All Hostels
* Monitor Bookings Across the Platform
* Manage Users
* View Reports and Statistics
* Platform Settings

### Hostel Admin

* Secure Login
* Dashboard
* Manage Hostel Information
* Manage Room Types
* Add, Update, and Delete Rooms
* Set Room Availability
* Manage Room Pricing
* View and Manage Bookings
* Check-in / Check-out Management
* View Customer Details
* Booking Reports

### Customer

* User Registration and Login
* Search Hostels
* Filter by Location, Price, and Room Type
* View Hostel Details
* View Room Availability
* Book Rooms
* Booking History
* Profile Management
* Cancel Bookings (if allowed)
* Contact Hostel

## 🏗️ System Architecture

The application follows a multi-level management architecture:

* **Super Admin**

  * Manages all hostel administrators.
  * Monitors the complete platform.
  * Controls platform-wide settings.

* **Hostel Admin**

  * Manages only their assigned hostel(s).
  * Handles room inventory and bookings.
  * Views reports related to their hostels.

* **Customer**

  * Searches hostels.
  * Books rooms.
  * Manages personal bookings and profile.

## ⚙️ Installation

1. Clone this repository.
2. Copy the project folder into the XAMPP `htdocs` directory.
3. Create a MySQL database.
4. Import the provided SQL file.
5. Update the database connection settings.
6. Start Apache and MySQL using XAMPP.
7. Open the project in your web browser.
